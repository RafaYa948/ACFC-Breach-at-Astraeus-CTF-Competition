## What This Tests

- The ability to recognise when no technical solution exists
- Lateral thinking, stepping back from tools and reading the narrative
- Persistence without tunnel vision, knowing when to stop digging

---

## Key Concept

Not every alert in a SOC queue has a technical solution. Not every file contains hidden data. One of the most important analyst skills is knowing when something is a dead end, and being able to articulate that clearly rather than continuing to chase a path that leads nowhere.

This challenge rewards analysts who read carefully and think critically over those who run every tool they know.
